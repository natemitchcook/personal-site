# Ruffi Points Roadmap

## Phase 1: local proof

- manual wallet
- natural-language award request
- normalized provider interface
- wallet-aware funding plans
- transparent result ranking
- watches and browser alerts
- optional email and text delivery
- HTTP API, OpenAPI, and local MCP tools

## Phase 2: prove live value

- validate the Seats.aero Pro adapter against real searches
- run 25 representative search scenarios
- measure availability accuracy, stale-result rate, search latency, and ranking quality
- measure local Ollama parsing and refinement accuracy
- add live verification before recommending a point transfer
- add transfer bonuses with provenance and expiration
- add cash-price comparison

## Phase 3: direct connector foundation

- connector test harness and normalized fixtures
- secure per-user session vault
- rate limiting and search-budget allocation
- connector health, parser drift, and bot-challenge detection
- American, United, Delta, Flying Blue, Aeroplan, British Airways, and Virgin Atlantic research spikes
- written permission or commercial access where required

## Phase 4: alliance and independent expansion

- Alaska, LifeMiles, Qantas, Qatar, Singapore, ANA
- Emirates, Etihad, and Virgin Australia
- cross-program deduplication
- partner-inventory discrepancy tracking
- historical availability and price-change index

## Phase 5: remote platform

- personal AWS deployment
- Postgres and durable job queue
- remote MCP over Streamable HTTP
- OAuth authorization for third-party agents
- per-user budgets, quotas, and audit logs
- email and text webhooks

## Success metrics

- percentage of searches with at least one verifiably bookable recommendation
- percentage of top recommendations the user agrees is best
- stale-result rate
- useful alerts per watch
- unwanted-alert rate
- provider cost per useful recommendation
- direct-connector coverage and health
