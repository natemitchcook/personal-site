03 / Implementation

Small changes.
A clearer handoff.

  1. Make the choices explicit

    Use meaningful labels and complete service names. Keep the same underlying rules and synthetic data.

  2. Make recovery actionable

    Point to the invalid field, explain eligibility and retain valid selections. Keep keyboard focus visible.

  3. Make the outcome verifiable

    Review the exact request, create a stable local receipt, and guard repeated submission. Both versions expose the same confirmation boundary.
